# 设计说明

> 与实现同步的精简设计文档。内部过程记录（逐版 bug 台账、校内材料编号等）不随本仓库发布。

## 一、目标

听课人在真实课堂里边听边记，事后能直接产出可用于评课讨论的材料，而不是课后凭记忆复述。
核心要求：**打标必须足够轻**（一次点击、不打断听课），**时间必须准**（每条标记对应真实课堂时刻），
**录音必须可靠**（熄屏/切后台仍在录，事后可回听核对）。

## 二、页面与流程

```
开始页 ──开始听课──▶ 计时页 ──结束──▶ 报告页 ──▶ 历史记录 ──▶ 历史报告（只读）
   ▲                    │                                     │
   └──编辑听课信息       ├─ 标签坞（轻点打标 / 长按补细节）      └──编辑听课信息、删除
                        ├─ 时间轴抽屉（改 / 删任意一条）
                        └─ 评课标记卡（⭐ 亮点 / ⚠️ 不足 / ❓ 疑问）
```

- 单 Activity + 一个 `Screen` 状态机，计时页不销毁；时间轴用底部抽屉覆盖
- 计时页拦截系统返回键 → 弹「退出听课？」（继续 / 结束本节）
- 结束前二次确认；结束即存档并跳报告页

## 三、标签体系

### 3.1 环节（一级标签，14 个）

导入 · 目标呈现 · 新授讲解 · 实验演示 · 学生实验 · 探究活动 · 提问互动 · 当堂检测 ·
巩固练习 · 小结 · 作业布置 · 板书板图 · 多媒体与信息技术 · 拓展延伸

标签坞 2×7 排布，轻点立即落一条打标，长按打开补充弹窗（子标签 / 备注）。

### 3.2 子标签（二级，可自定义）

每个环节带若干预设子标签（如「探究活动」：提出问题 / 猜想假设 / 方案设计 / 实验验证 / 分析论证 / 成果展示），
另提供「自定义…」可自由输入。子标签是自由文本字段，不限制取值范围。

### 3.3 评课标记（独立点事件）

亮点 / 不足 / 疑问 三类，可附备注。**独立成条**：记在时间轴上，但不占用环节时长、不计入环节占比，
因此不影响「这节课各环节各花多久」的统计。

## 四、数据结构（Room）

```
sessions  一次听课
  id, title, cls, teacher, observer, date, period, count, place,
  stage, subject, teacherOrg, observerOrg,          -- v1.6.1 新增
  startedAt, endedAt(null=进行中), elapsedSec, hasAudio

marks     打标（外键 sessionId，ON DELETE CASCADE）
  id, sessionId, ts(秒), label, sub, eval, note

audio_segments  录音分段（外键 sessionId，ON DELETE CASCADE）
  rowId, sessionId, segIndex, path, startSec, endSec, mime
```

版本演进：`version 1 → 2` 增加 `teacherOrg / observerOrg / stage / subject`，用显式 `Migration`
（`ALTER TABLE ADD COLUMN`）完成，**不使用 destructive fallback**，避免升级清空历史记录。

## 五、统计口径

- **环节时长**：某条环节标记的时长 = 下一条环节标记的时刻 − 本条时刻；末段 = 结束时刻 − 末条时刻
- **未打标段**：0 → 首个环节标记；若一条环节标记都没有，整节都算未打标
- **占比** = 该类累计时长 ÷ 总计时，保留 1 位小数（可能出现合计 < 100%，差额即未打标）
- **评课标记**：点事件，不参与以上任何计算（代码统一先经 `envMarks()` 过滤）

## 六、实现要点

| 关注点 | 做法 |
|---|---|
| 打标时刻被保存时间污染 | 打开弹窗时把当时时刻冻结进 `TagEditState.ts`，保存只用这个值 |
| 熄屏/切后台录音静音 | `RecordingService` 前台服务（`foregroundServiceType="microphone"`），录音前 `startForegroundService` |
| 历史打标全丢 | `sessions` 用 `@Upsert`（INSERT … ON CONFLICT DO UPDATE）；SQLite 的 `INSERT OR REPLACE` 是「先删再插」，会触发 `marks` 的级联删除 |
| 旋转屏幕导致回放中断 | 锁竖屏（Manifest `screenOrientation="portrait"` + `requestedOrientation`），并声明 `configChanges` 防止 Activity 重建 |
| 冷启动丢本节 | `endedAt = null` 的行即"进行中"，启动时恢复计时与已打标（录音不恢复） |
| 导出粘 Excel 乱码 | CSV 加 UTF-8 BOM |

## 七、导出

| 形式 | 说明 |
|---|---|
| 文本时间轴 | 三行表头（课题 + 学段科目 + 时长 / 班级·授课教师（单位）·日期·节次 / 听课人（单位）），逐条标记 + 环节占比 + 评课清单 |
| CSV | 序号,时间(秒),时间,环节,子标签,评课标记,环节时长(秒),备注,学段,科目（带 BOM） |
| 占比长图 | Canvas 生成 900px 宽 PNG，直接发群 |
| 录音 | 单段 / 多段分享，`FileProvider` + `ACTION_SEND`，可存文件、发微信、传网盘 |

## 八、已知限制

1. 录音器是进程内单例；极端省电策略下进程被杀，录音仍会中断（彻底方案是把 MediaRecorder 移进 Service）。
2. 音频存 App 私有目录，卸载即失效；删除听课记录会一并删除该节音频文件。
3. 历史记录只能改听课信息，不能改/补历史打标（时间轴里可改删本节内打标）。
4. 仅手机竖屏，不做平板/横屏布局。
5. 无云端同步、无账号体系，全部数据在本机。
