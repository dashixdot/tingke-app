# 听课打标 App（Android / Kotlin + Compose）

面向中学物理教研组随堂听课、评课与教研复盘：**计时 + 一键打标 + 同步录音 + 环节占比**。

本工程是设计方案 v1.2 的安卓实现，交互与原型 `../../03-文档/听课打标APP-交互原型-v1.2-20261103.html` 保持一致。

> 目录结构：本工程位于 `听课打标APP\01-工程\听课打标APP-android`，配套的设计方案与原型在 `docs`，
> 安装包在 `Releases`，原型截图在 `docs/screenshots`。层级说明见 `README.md`。

## 一、当前状态

- ✅ 可编译，已产出 `app-debug.apk`（约 16 MB，versionName **1.6.1**）
- ✅ 功能闭环：开始页（默认勾选录音）→ 计时页（标签坞一键打标）→ 时间轴抽屉 → 报告页（占比/文本/CSV）→ 历史记录

## 一之二、v1.3 真机问题修复记录

| # | 真机现象 | 根因 | 修复 |
|---|---|---|---|
| 1 | 熄屏/切后台录音**没声音** | Android 9+ 应用后台时麦克风被静音，没有前台服务 | 新增 `RecordingService`（`foregroundServiceType="microphone"`），录音前 `startForegroundService`，停止时 `stopService`；补 `FOREGROUND_SERVICE_MICROPHONE` / `POST_NOTIFICATIONS` 权限 |
| 2 | 回到历史记录**打标全丢** | `SessionDao.upsert` 用了 `OnConflictStrategy.REPLACE`，SQLite 的 `INSERT OR REPLACE` 是**先 DELETE 再 INSERT**，触发 `marks` 表 `ON DELETE CASCADE` 把整节打标删光（`persistSnapshot()` 每次打标都会重写 session 行） | sessions 改 `@Upsert`（INSERT…ON CONFLICT DO UPDATE，不删行）；另加 `sessionJob.join()` 保证 session 先落库再插 marks，避免外键失败 |
| 3 | 录音回放**没进度**，播完仍显示"暂停" | 只做了播放/暂停，没有进度与完成回调 | `AudioRow` 重写：`prepareAsync` + `onPrepared` 取时长、`Slider` 可拖动、`200ms` 轮询位置、`onCompletionListener` 复位状态与进度 |
| 4 | 打标提示条**挡住标签坞** | Toast 定位在底部 `bottom = 116dp`，正好压在标签坞上 | Toast 移到顶部（顶栏下方 92dp） |
| 5 | 返回键**直接回桌面** | 未拦截返回键 | 计时页 `BackHandler` → 弹「退出听课？」（继续听课/结束本节）；历史页返回 → 主页面（计时中则回计时页）；结束后报告 → 主页面；历史进入的报告 → 历史。另在历史/报告顶栏加「‹ 返回」 |
| 6 | 需求：录音要能**分享/导出** | — | 每段录音带「分享」（`ACTION_SEND` + FileProvider，可在系统面板里存到文件/网盘/微信）；多段时提供「分享全部录音」（`ACTION_SEND_MULTIPLE`） |

## 二之二、v1.4 变更（竖屏锁定 + 历史信息可改）

| # | 问题 / 需求 | 根因 | 处理 |
|---|---|---|---|
| 1 | 手机**自动横屏**后，录音回放**停止并跳回开头** | 横竖屏切换触发 Activity 重建，`AudioRow` 里的 `MediaPlayer` 被 `onDispose` 释放，`remember` 的播放进度/状态一起丢失 | ① `AndroidManifest` 给 `MainActivity` 加 `android:screenOrientation="portrait"`，并在 `onCreate` 里再 `requestedOrientation = PORTRAIT`（防个别 ROM/分屏策略忽略 Manifest）；② 同时声明 `configChanges="orientation|screenSize|screenLayout|smallestScreenSize|keyboardHidden|navigation"` 兜底：即使系统强转，Activity 也不重建，计时/打标/回放状态全部保留 |
| 2 | 全竖屏 | 产品口径调整：本期**只做手机，不做平板**，不维护横屏布局 | 同上锁定竖屏；界面按竖屏单列布局，标签坞 2×7 排布不变 |
| 3 | 需求：**历史记录中要能修改听课信息** | 原先历史只能看和删 | 历史列表每条加「编辑信息」，历史报告页顶栏加「编辑信息」，复用 `InfoEditorDialog`（课题/授课教师/班级/听课人/日期/节次/班级人数/地点）；保存走 `SessionDao.@Upsert` 只改信息字段（不删行），**打标、录音分段、时长都不受影响**；同时刷新历史列表与报告页表头，导出的文本/CSV/占比长图立即使用新信息 |
| 4 | 竖屏窄屏下信息弹窗 8 个输入框超高度 | — | `InfoEditorDialog` 内容区 `heightIn(max = 420.dp)` + 纵向滚动 |

## 三、怎么构建

### 命令行

```bat
cd /d 本仓库根目录
set JAVA_HOME=E:\Android\jdk
gradlew.bat assembleDebug
```

产物：`app\build\outputs\apk\debug\app-debug.apk`

### Android Studio

1. `File → Open` 选择本目录
2. 等 Sync 完成（首次会下依赖）
3. `Run ▶` 或 `Build → Build APK(s)`

依赖仓库：`google()`（实际走 `dl.google.com/dl/android/maven2/`）+ `mavenCentral()`。
若公司网络受限，可在 `settings.gradle.kts` 里加阿里云镜像：
`maven { url = uri("https://maven.aliyun.com/repository/google") }`

Wrapper 的 `distributionUrl` 已指向腾讯云镜像（官方源在本机下载会被重置），
如需恢复官方源，改 `gradle/wrapper/gradle-wrapper.properties` 即可。

## 五、关键设计在代码里的落点

对应《设计方案 v1.2》第十二节列出的问题，实现时的对应处理：

| 编号 | 问题 | 代码位置 |
|---|---|---|
| A1 | 进得去出不来 | 单 Activity + `Screen` 状态机（`MainViewModel.screen`），计时页不销毁；时间轴用 `ModalBottomSheet` 覆盖；历史页在 `vm.running` 时显示「返回计时」 |
| A2 | 打标时刻漂移 | `TagEditState.ts` 在打开弹窗时冻结，`commitMark(...)` 只用这个 ts |
| A3 | 结束即丢数据 | `endSession()` 把 `endedAt` 写入 `sessions`，不再清空；结束前 `AlertDialog` 二次确认 |
| A4 | 录音异步时序 | `AudioRecorder.stop()` 同步收尾并在 `endSession()` 中先落段、再存库、再切报告页 |
| A5 | 分段覆盖 | `AudioRecorder` 每次 `start` 新文件，`stop` 返回该段，追加到 `segs` 列表，不覆盖 |
| A6 | 占比不足 100% | `unmarkedDur()` + `ShareData.unmarked`，报告页单列「未打标」行 |
| B1 | 打标太重 | 14 个标签常驻 `Dock`，`detectTapGestures` 轻点即 `quickTag()` 落库 |
| B3 | 无撤销 | `tell(text, "撤销") { undoMark(id) }`，5 秒内可撤 |
| B6 | 录音要二次点击 | 开始页 `Checkbox` 默认勾选，`startSession()` 内直接 `recorder.start()` |
| B9 | 日期 UTC 偏移 | `todayStr()` 用 `Calendar` 取本地日期 |
| C4 | 状态文字不更新 | 计时页状态文字由 `vm.running/paused/marks` 直接派生，不留旧值 |

## 六、已知限制 / 下一步

1. **前台服务只保进程、不接管录音**：录音器仍是进程内单例（`RecorderHolder`）。若系统在极端省电策略下杀进程，录音仍会中断；彻底方案是把 MediaRecorder 移进 Service。
2. **历史记录音频路径失效风险**：音频存 App 私有目录 `files/recordings/`，卸载即失效；未做批量导出归档。
3. **未做自定义标签**、未对接组内听课评价表、无云端同步。
4. 标签短名（导入/目标/讲解…）为适配 7 列布局，可在 `domain/Core.kt` 的 `LabelDef.short` 调整。
5. **只支持手机竖屏**：平板横屏布局本期不做；若将来要支持平板，需移除 Manifest 的 `screenOrientation` 并补横屏两栏布局。
6. 历史记录只允许改**听课信息**（课题/教师/班级等）；历史打标与录音回听仍为只读（未做历史打标编辑/补录）。
